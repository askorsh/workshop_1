# Workshop 1 — Python-клиент для SampleAPIs Coffee

Лабораторная работа в рамках курса от **X5 Group**.

## Задача

Исследовать незнакомый публичный API (SampleAPIs Coffee) и написать
Python-клиент на библиотеке `requests`, который умеет:

- получать список горячих напитков;
- находить напиток по `id`;
- создавать новую запись;
- полностью заменять запись (PUT);
- частично изменять запись (PATCH);
- удалять запись (DELETE).

Спецификации API не выдавалось — структура данных и поведение
определены самостоятельно через реальные HTTP-запросы.

## API

Базовый URL: `https://pycourse-2026.duckdns.org/coffee/hot/`

| Операция | Метод + путь | Успех | Тело ответа |
|---|---|---|---|
| Список | `GET /coffee/hot/` | 200 | массив объектов |
| Один напиток | `GET /coffee/hot/<id>/` | 200 | объект |
| Отсутствует | `GET /coffee/hot/<id>/` | 404 | `{}` |
| Создать | `POST /coffee/hot/` | 201 | объект с id + `Location` |
| Заменить | `PUT /coffee/hot/<id>/` | 200 | объект |
| Изменить | `PATCH /coffee/hot/<id>/` | 200 | объект |
| Удалить | `DELETE /coffee/hot/<id>/` | 200 | `{}` |

### Схема объекта напитка

```json
{
  "title": "string",
  "description": "string",
  "ingredients": ["array", "of", "strings"],
  "image": "string",
  "id": 59
}


Программа выполняет полный сценарий из 8 шагов:

GET коллекции
POST — создание напитка с уникальной меткой группы
GET по id из ответа POST
PUT — полная замена
PATCH — частичное изменение
GET — проверка изменений
DELETE
GET — убедиться, что вернулся 404
Реализованные требования

Запросы через requests, без Session.
Тайм-аут задаётся для каждого запроса.
HTTP-статус проверяется до вызова .json().
Проверяется Content-Type: application/json.
404 (CoffeeNotFoundError) отличается от остальных ошибок API (CoffeeApiError).
id берётся из ответа POST.
Созданная запись удаляется в блоке finally при любой ошибке.
Работа только со своими записями — чужие не изменяются.
